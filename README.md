## What this repository does
Running one file rebuilds everything — cleaned data, every estimate, the table, and the figure — from the raw files. No number in your memo is ever typed by hand.

## How to run it
1. Download or clone this repository and open Stata **in this folder** (or `cd` to it).
2. Type:
   ```
   do master.do
   ```
   That runs `01_build.do` → `02_simulation.do` → `03_analysis.do`, and writes a log plus all tables and figures into `output/`.

## Folder layout
```
master.do            runs everything, in order
code/01_build.do     clean the raw PSID file; assemble the two analysis datasets
code/02_simulation.do  Part 1 (set your student number as the seed)
code/03_analysis.do    Part 2 (experiment vs OLS)
data/raw/            the two files you were given — do not edit these
output/              generated tables and figure (committed, so they can be checked)
memo/                LaTeX template for your Part 3 memo; it \inputs output/results.tex
```
